# Extractive-Question-Answering-System-with-Unanswerable-Query-Detection-using-BERT
Engineered an end-to-end extractive Question Answering pipeline by fine-tuning a 109M-parameter pre-trained BERT model (bert_base_en_uncased) using TensorFlow, KerasHub, and multi-GPU MirroredStrategy on the SQuAD 2.0 dataset comprising over 130,000 training examples. Implemented sliding-window context tokenization with stride overlap, custom span-reconstruction post-processing, and null-score threshold optimization, achieving 74.99% F1-score and 72.04% Exact Match across 11,873 validation queries.
